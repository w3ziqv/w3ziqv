## 🚀 Featured Projects

### [GitScore](https://github.com/w3ziqv/gitscore) ⭐ *NEW*
Full-stack GitHub profile analyzer with gamification, roast mode, and shareable score cards.
- **Stack:** React 19 · TypeScript · Vite · Express · SQLite · Node.js 22
- **Features:** Profile scoring, achievement badges, fun stats, share cards
- 🔗 [Live Demo](https://gitscore-mu.vercel.app/)

### [Geometria Nieskończoności](https://github.com/w3ziqv/geometria-nieskonczonosci) 🥈
Interactive fractal geometry educational site — Mandelbrot set, Julia sets on Canvas.
- **Award:** 2nd prize — national *See Mathematics* competition (AGH)
- **Stack:** Vanilla JS · HTML5 Canvas · CSS3
- 🔗 [Live Demo](https://geometria-nieskonczonosci.vercel.app/)

### [Weather App](https://github.com/w3ziqv/Weather-app) 🌤️
Minimalist weather UI with live data, forecast, air quality, and geolocation.
- **Stack:** TypeScript · Vite · Vitest · PWA · CI/CD
- **Features:** 5-day forecast, air quality index, geolocation, offline support
- 🔗 [Live Demo](https://weather-app-five-taupe-24.vercel.app/)

### [Focus Flow](https://github.com/w3ziqv/focus-flow) 🍅
Minimalist Pomodoro timer with focus mode, weekly statistics, ambient sounds.
- **Stack:** Vanilla JS · CSS3 · PWA
- **Features:** Focus mode, weekly stats, rain/pink noise, study tips
- 🔗 [Live Demo](https://focus-flow-self-ten.vercel.app/)

### [Swift Task Tracker CLI](https://github.com/w3ziqv/swift-task-tracker-cli) ⌨️
Command-line task manager with JSON persistence, priorities, and ANSI colors.
- **Stack:** Swift · JSON · Terminal UI
- **Features:** Task priorities, color-coded output, input validation
